# Risky Wiring

Risky Wiring is a Unity game about building circuits on a grid and keeping the power flowing under pressure.

## Run the project

1. Open this folder in Unity Hub with **Unity 6000.3.20f1**.
2. Open `Assets/Scenes/SampleScene 1.unity` and press **Play**.
